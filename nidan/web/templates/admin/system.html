What exists instead, today

The audit trail is real and is already on the Dashboard. audit_log refuses both UPDATE and DELETE — to the table owner included — so it is append-only in the database rather than by convention. It is also the jobs queue: a request is done when its per-step completion rows exist, which is why a crash between a remote call and its completion row costs one retry rather than a lost request.

There are no feature flags. What would live here is configuration — the free-tier allowance, model selection, prices — and all of it is environment and pyproject today. The allowance in particular is configured and not schema on purpose: it is a pricing decision, and pricing changes faster than schemas.
