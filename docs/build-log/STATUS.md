## The thing this table cannot show

Every number above is engineering effort. **Ten clinically reviewed cases gate launch and five exist.** No task in this plan produces one: writing a case is clinical authoring, not development, and it needs no developer time.

The two clinician reviewers cannot start until **T-021** (case editor) and **T-023** (review workflow) exist, because until then only a programmer can read a case. That is 12 days of Phase 2 work away, and authoring the drafts can begin before it.

`BUILD_PLAN` §11.1 rates this **the** risk to the schedule, and it is the one a task tracker makes easy to forget — because it has no task.
